Integration Control Centre (ICC)

Central hub for SAP B1 / Neon webhook integrations

Key Features

  • Webhook Endpoints — Receive JSON payloads from SAP B1 / Neon middleware via channel-specific URLs
  • Channel Management — Enable/disable endpoints per document type with per-channel API key authentication
  • Event Audit Trail — Full log of every inbound and outbound event with payload, timing, and status
  • Health Dashboard — Kanban overview with health indicators and throughput graphs
  • Retry Failed Events — One-click retry for failed webhook events directly from the event log
  • Fallback Polling — Safety-net cron that catches records missed by webhooks
  • Log Cleanup — Configurable retention period with automatic purge cron

Supported Channels

  • Invoice Sync (account.move)
  • Delivery Sync (stock.picking)
  • Payment Sync (account.payment)
  • Customer Sync (res.partner)
  • Product Sync (product.product)
  • Sales Order Sync (sale.order)

Architecture

SAP B1  -->  .NET Middleware (Quartz)  -->  Neon DB  -->  POST /icc/webhook/{channel}
